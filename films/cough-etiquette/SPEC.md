# 기침 예절 개념 장면 — SPEC

- 쓰는 곳: 연구 기록 > "핵심 개념 세 장면으로 기억하기" 두 번째 장면(기침 예절과 환기). 정지 그림 한 장(가린 모습만)으로는 '가리기 전과 후'의 차이가 보이지 않아, P06 비말 실험에서 학생이 직접 본 전·후를 다시 보여 준다.
- 한 생각: 옷소매로 입과 코를 가리면 비말이 퍼지는 범위가 줄어든다. 0이 되지는 않는다(앱 실험과 같다: 5개 중 2개가 남고 3개는 흐려짐).
- 형식: 1920×1080, 30fps, 13.5초, 무음(앱 효과음은 코드 합성이라 파일이 없다. 앱에서도 음소거 재생). 앱용 1280×720 H.264 mp4 + VP9 webm, 포스터는 마지막 프레임.
- 그림: 게임의 `cough-before-20261108`, `cough-covered-20261108`(같은 그림을 뒤집어 친구로), `title-mate`(마지막 반응). 비말 점·점선·이름표만 코드로 그린다.
- 색: 게임 토큰 그대로. 종이 #F6FBFB, 모눈 #CFE5E4, 글자 #103E43, 비말 #7556D4/#D9CCF7, 줄어든 뒤 #0A7069.
- 글꼴: 게임과 같은 시스템 한글 글꼴(Apple SD Gothic Neo, local). 제목 64px/800, 이름표 34px/700, 결론 56px/800.
