## 1. 놀이 영역 크기·위치·배경 조화

놀이 영역 = 활동 화면의 `.page-content` 안 실제 내용 덩어리(위 띠·아래 띠 제외). 지도는 픽셀 지도 캔버스, 첫 화면은 제목 장면.

| 뷰포트 | 활동 P01~P10 높이 | 면적 | 좌/우 빈 띠 | 위/아래(띠 포함) | 판정 |
|---|---|---|---|---|---|
| 1280×800 | 73.4~75.1% | 71.2~72.7% | 1.6% / 1.6% | 15.4~16.7% / 9.5~11.1% | 통과 |
| 1024×768 | 72.5~74.1% | 69.6~71.2% | 2.0% / 2.0% | 16.0~17.3% / 9.9~11.5% | 통과 |
| 1920×1080 | 79.8~81.2% | 78.1~79.5% | 1.0% / 1.0% | 11.8~12.9% / 7.0~8.4% | 통과 |
| C00·C01 (세 뷰포트) | 100% | 100% | 0 / 0 | 0 / 0 | 통과 |

- 위쪽 15~17%는 빈 배경이 아니라 위 띠(64px)와 개념·질문 한 줄 띠(47~52px)다. 아래쪽은 actionbar(64px)다. 놀이 영역 바깥 빈 배경 띠는 좌우 1~2%뿐이다.
- 중심 쏠림 0%(가운데 정렬), 1920×1080에서도 고정 `max-width`로 작아지지 않는다(이미 뷰포트 기준 그리드).
- 배경은 `body.has-stage-bg`의 장면 그림 + 반투명(.8) 유리 패널·blur로 받아들이고 있다(2026-11-16 흐름 고도화). 큰 불투명 판은 없다.

**수정안:** 크기·위치 수치가 세 뷰포트 모두 기준(높이 70%↑, 면적 55%↑, 빈 띠 15%↓)을 넘어 **배치 변경은 하지 않는다.** 기준 밖 큰 재디자인(위 띠 두 줄을 한 줄로 합치는 구조 변경)은 이번 범위가 아니어서 제안만 남긴다: 1024×768에서 개념 띠(47px)를 위 띠 제목 옆으로 올리면 놀이 높이가 약 6%p 더 커진다.

## 2. 중복 조작 버튼 전수 점검

방법: 위 스크립트가 화면마다 보이는 button·select·input·draggable 목록(글자·aria-label·data-action)을 뽑고, 스크린샷과 코드로 같은 일을 하는 진입점을 찾았다.

| 화면 | 중복 | 처리(채택) |
|---|---|---|
| P06 비말 | 끌 수 있는 「옷소매를 입으로 끌어요」 칩 + 같은 일을 하는 「눌러서 가리기」 버튼 | 칩을 버튼 하나로 합침. 끌어도, 눌러도, Enter/Space로도 가려진다(`data-drag="sleeve"` + `data-action="lab-set"`). 가린 뒤 「가리기 전 보기」만 남음 |
| P06 공기 | 「닫기」·슬라이더·「열기」 세 개가 같은 창문을 여닫음(+창문 밀기 손짓) | 슬라이더를 뺌(작은 화면에서는 원래 숨겨져 있었다). 「닫기」「열기」 두 버튼 + 창문 손짓 유지 |
| P06 타액 | 「개인 접시」 버튼과 아래 「개인 접시에 덜기」 버튼이 같은 일 | 아래 버튼을 빼고 접시를 강조(`next-target`). 끌기(덜기 도구→접시)와 접시 누르기 둘 다 그대로. 지시 문장을 「덜기 도구를 개인 접시로 끌거나 개인 접시를 눌러 …」로 맞춤 |
| P06 실험 탭 | 다음 실험 탭이 빛나는데 장면 안 「다음 실험: ○○」 주 버튼도 빛남(같은 동작 두 곳) | 탭의 강조를 빼고 주 버튼 하나만 강조. 탭 이동 자체는 그대로 |
| P10 아래 띠 | 오른쪽 아래 「연구 기록」 버튼 = 위 띠 연구 기록 아이콘 | 아래 띠 버튼을 뺌. P10 주 행동은 장면 안 버튼(직접 실천하기·창문 밀어 열기 등) |
| P10 엔딩·인증서 카드 | 「연구 기록」「조사 지도」 = 위 띠 연구 기록·지도 아이콘 | 카드에서 두 버튼을 빼고 「조사 인증서」/「인증서 출력」 주 버튼 하나만 남김. 지도·기록은 위 띠 같은 자리에서 연다 |
| C01 지도 「건강한 학교 복구」 창 | 「창문 손잡이 밀기」 슬라이더와 「손잡이를 잡아 창문 열기」 버튼이 같은 일 | 슬라이더를 뺌. 버튼 하나로 연다(복구 단계 판정·저장은 그대로) |

유지(중복 아님, 이유):
- C01 지도: 장소 이름표 버튼과 오른쪽 아래 「○○으로 가기」 — 이름표는 지도 위 물체(다시 실험·카메라 밖 장소 포함), 주 버튼은 3초 목표. 3초 문서가 정한 배치.
- P05: 비누 방패(끌기 원본)와 시점 버튼(놓을 곳이자 누르기 대상)은 한 동작의 두 끝이다. 낮은 화면의 시점 select는 버튼이 숨을 때만 보인다.
- P02·P03·P04·P09: 장소·단계 탭과 단서 넘기기는 작은 화면에서만 보인다(1024px 이상 숨김, 측정 목록으로 확인).
- P07 다섯 행동·P08 결과 카드: 판단 단계라 고를 영역 전체를 같은 무게로 표시(3초 규칙).
- P10 환기: 창문은 밀기 손짓만 받고 누르기는 안 받으므로 「창문 밀어 열기」 버튼이 유일한 누르기·키보드 경로다.

지키는 것: 홈·뒤로(왼쪽 위 지도), 소리·설정(오른쪽 위), 주 버튼(오른쪽 아래 「다음 조사」) 자리. 학습 판정·저장·진행 로직은 바꾸지 않았다(없앤 것은 화면 진입점뿐, 각 동작마다 남은 경로가 있다).
