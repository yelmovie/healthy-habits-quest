# 12 보이지 않는 흔적 고도화 검토

2026-11-07. 대상: invisible-traces. 기존 미커밋 작업과 자산을 보존했다. 커밋·배포·영구삭제 없음.

## 실제 적용
- 교사용 전 미션 시연에서 이미 열린 첫 미션도 예시 상태로 시작한다. 시연 진입부터 본편 원본을 분리하고 시연 설정 변경도 원본에 반영하지 않는다.
- 저장 시 마지막으로 읽은 원문과 현재 저장값을 비교하여 다른 창의 새 기록을 덮어쓰지 않는다. 충돌·저장 실패·손상 데이터에는 지속 안내를 표시한다.
- 초기화 전에 원본 문자열을 별도 복구 사본으로 보존한다. 이전 사본이 있으면 새 키를 사용한다. 백업 실패 또는 다른 창 변경 시 초기화를 취소한다. 손상/미래 버전도 무단 교체하지 않는다.
- 저장 안내가 조작을 가리지 않도록 문서 흐름에 배치했다.
- 500px 이하 낮은 가로 화면에서 하단 이동 바를 고정하지 않아 실험 내용을 가리지 않게 했다.

## 학습 흐름·정확성
P01 위치 발견 → P02 중요 단서 선택 → P03 관계 연결 → P04 생활 영향 → P05 시간·개입 시점 → P06 전달 경로 → P07 한 행동만 바꾸기/예측 → P08 관찰 근거 설명 → P09 제한 조건의 계획 → P10 직접 적용으로 역할이 구분된다. P07/P08과 P09/P10은 같은 자료를 쓰되 예측-근거, 설계-실행으로 다른 사고 활동이다. 중복 화면 삭제보다 이 연속성을 유지했다.
기존 PRD의 [4과08-01~03] 매핑을 확인했다. 이번 작업에서 교육과정 원문이나 운영시트 최신본을 독립 재검증하지 않았다. 흔적은 실제 감염 진단/확률이 아니며, 사람 낙인 대신 행동·환경을 다룬다는 기존 안내를 유지했다. 학습 효과는 실제 학생 수업으로 확인하지 않았다.

## 적용한 개선 프롬프트
“12번 보이지 않는 흔적의 기존 타이틀·지도·수업 흐름과 미커밋 변경을 보존하라. 교사 시연이 학생 본편에 절대 저장되지 않도록 진입, 첫 미션, 설정, 복귀를 분리하라. 손상 저장·미래 버전·다중 탭·저장 실패·초기화 백업 실패에 대한 회귀 테스트를 먼저 추가하고, 기존 기록을 무단 덮어쓰지 않게 수정하라. 1280×800, 915×412, 390×844에서 10개 활동을 확인하고 조작 가림을 수정하라. 코어 학습 내용을 장식용 애니메이션/음향으로 대체하지 말고 신규 자산은 필요한 경우에만 추가하라. 커밋·배포하지 말고 검증 결과와 미검증 범위를 기록하라.”

## 재현·검증
- npm test: 30/30 통과(기존25 + 저장 방어5).
- npm run check / npm run build 통과. 기존 Phaser 약1.2MB 분리 청크 경고는 남아 있음.
- 독립 Chromium: docs/reviews/series12-qa/check.mjs (로컬 개발서버 5342 필요).
- 실제 교사 시연 첫 미션 조작 및 큰 글자 설정 후 localStorage 원문 불변 확인.
- 손상 JSON 상태에서 조사 시작 후 원문 보존 및 지속 안내 확인.
- P01~P10 예시 상태를 각 3 화면 크기로 로딩하여 수평 넘침/깨진 이미지 없음. 30 화면은 fixture 기반 검사이며 학생의 10장 연속 수동 완주를 뜻하지 않는다.
- 결과: series12-qa/results.json, P07 크기별 PNG.
- 낮은 가로화면 하단바는 스크린샷 확인 후 추가 수정했다.

## 한계 및 후속
학교망 동시접속, 실제 iPad/Android 터치, 전체 오프라인 캐시 업데이트, 전체 학생 경로 연속 플레이, 스크린리더는 미검증. localStorage 비교는 일반적인 순차 다중탭 덮어쓰기를 막지만 데이터베이스 수준 원자적 잠금은 아니다. 원문 복구 사본은 개발자 도구에서 복원할 수 있고 UI 복원 기능은 별도 과제다. NPC 신규 음성이나 모모 생성은 하지 않았으며 기존 음향을 유지했다. 공통 graphify 증분 갱신은 전체 시리즈 마무리 시 한 번 수행하도록 상위 작업에 전달했다.
