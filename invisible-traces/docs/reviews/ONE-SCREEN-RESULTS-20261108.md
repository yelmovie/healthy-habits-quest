# 한 화면 활동·자동재생 개선 결과

작업일: 2026-11-08

## 적용한 동작

5스테이지·학습 10장의 실험 장면과 조작을 한 화면에 배치했다. 왼쪽 진행 목록과 별도 제목 행을 없애고, 한 줄 헤더·크게 쓰는 활동 영역·하단 이동으로 정리했다. 작은 화면은 같은 페이지의 탭·장소 선택·단서 넘기기로 초점을 바꾸며, 페이지를 스크롤하지 않는다.

- P01: 큰 현장 사진과 스캔. 작은 화면은 한 장소씩 보고 전환한다.
- P02: 장소별 단서와 단서함. 작은 화면은 장소 선택 메뉴·단서 번호·단서/단서함 탭을 쓴다.
- P03·P04: 단서/영향을 선택하면 연결 대상이 강조된다. 작은 화면에서는 대상 보기로 자동 전환하고 연결 후 다음 카드로 돌아간다.
- P05: 큰 접촉 경로와 개입 시점, 재생·속도·시간 막대를 고정 배치했다. 공간이 좁으면 시점 선택 메뉴를 쓴다.
- P06: 오른쪽 연구노트를 없애고 장치를 전체 폭으로 키웠다. 다섯 실험과 종합 문제는 여섯 탭으로 전환한다.
- P07·P08: 행동과 예측 선택, A/B 그림과 결과 연결이 같은 화면 안에 들어간다.
- P09: 장소 그림과 행동 배치를 크게 쓰고 현장 질문은 필요할 때 연다. 이미 들은 답을 다시 읽어도 질문권이 줄지 않는다.
- P10: 계획 그림과 실천을 중심으로 정리했다. 현재 계획의 조작·재생이 한 화면에 있고, 엔딩의 중복 기록 버튼도 정리했다.

반복 안내·결과 설명·연구 기록 목록을 줄였고, 다음 조작은 테두리·버튼 상태·단계 번호·초점 전환으로 안내한다. 공통 학습 모형 고지는 하단 정보 버튼으로 한곳에 모았다.

## 자동재생 범위

| 활동 | 자동으로 하는 과정 | 학생이 직접 하는 판단 |
| --- | --- | --- |
| 현장 관찰 | 세 장소의 신호 관찰·기록 | 중요한 단서 고르기 |
| 시간 추적 | 현재 조건의 시간 경과 | 시작점·손 씻을 시점 선택 |
| 연구실 | 접촉 순서, 기침 가리기·환기·덜기 전후 관찰 | 물 고르기·종합 문제 |
| A/B 비교 | 같은 시각의 두 장면 재생 | 행동·예측·차이 표시·결과 연결 |
| 최종 실천 | P09에서 확정한 계획 순서대로 적용 | 대응 계획 설계 |

속도는 0.5배·1배·2배이며 일시정지 후 이어서 재생할 수 있다. 속도를 바꾸면 기존 타이머를 지우고 하나만 다시 예약한다. 화면·실험 변경, 설정·안내 창 열기, 백그라운드 전환 시 재생을 중단한다. 완료된 기록은 관찰용 상태만 바꾸고 본편 기록을 보호한다. 저장 스키마와 기존 정답·해금 판정은 유지했다.

## 검증

- `npm run build`: 타입 검사·프로덕션 빌드·오프라인 캐시 목록 생성 통과.
- `npm test`: 33/33 통과. 자동재생의 정답 제외·계획 키·속도 제한 테스트 3개를 포함한다.
- 한 화면 검사: 32개 화면 상태 × 10개 해상도 × 기본/큰 글자 = **640개 조합, 검출 문제 0건**.
- 검사 항목: 문서·활동·내부 패널의 스크롤, 활동 밖·가려진 조작, 44px 미만 조작, 버튼 밖 글자, 글자·아이콘 겹침, 숨김 영역에 잘린 글자, 깨진 이미지, 페이지 오류. 스크린리더 전용 재생 상태 문구는 시각적 잘림 검사에서 제외했다.
- 해상도: 1920×1080, 1366×768, 1280×800, 1024×768, 1024×600, 915×412, 740×360, 800×270, 390×844, 360×740.
- 실제 브라우저 전체 플레이: 1180×820 및 390×844에서 메인→지도→P01~P10→엔딩·인증서 성공. 새로고침과 다시 실험 후 본편 기록 보존 확인.
- 자동재생·질문 UI 브라우저 검증 9항목 통과: 스캔, 속도 차이·일시정지/재개, 설정 창 중단, 판단 문제 수동 유지, 실험 전환 시 취소, 완료 기록 보호, A/B 판단 대기, 질문권 갱신·재열람, 확정 계획 자동 실천.
- 대표 스크린샷을 열어 큰 장면·작은 화면의 탭·초소형 조작 배치를 확인했다.

실물 태블릿·삼성 인터넷·iOS에서의 터치·회전은 미실측이다. 기존 Phaser 분리 청크의 500KB 초과 빌드 안내는 남아 있다.

## 재검증과 저장 위치

앱 폴더에서 `node scripts/check-one-screen.mjs after`, `node scripts/check-playback.mjs`로 브라우저 검증을 재실행할 수 있다. 로컬 개발 서버는 127.0.0.1:5342를 사용한다.

상세 결과·스크린샷·전체 플레이 기록·브라우저 임시 데이터는 프로젝트 루트의 `.tmp/one-screen-20261108/`에 있다. 새 코드·테스트·빌드·캐시·임시 파일은 연결과 쓰기 가능 상태를 확인한 외장 SSD에 저장했다.
