# 스테이지 반응형·학습 표현 개선

작업일: 2026-11-08

5스테이지의 학습 10장(P01~P10)을 세 작업자가 영역별로 나눠 개선했다. 공용 스타일과 브라우저 검증은 한 작업자가 통합했다. 기존 수정 내용과 저장·진행 판정은 보존했다.

## 확인한 문제와 수정

- 세로 폰의 P05: 6개 노드가 폭의 14%씩 차지해 이름이 여러 줄로 찢어지고, 설명줄이 마지막 노드를 가렸다. 좌표 배치를 없애고 화면 폭에 따라 6열·3열·2열로 바뀌는 경로와 번호·화살표를 적용했다.
- 단서 카드: 선택 표시·아이콘·설명이 같은 공간을 차지할 수 있었다. 각각 문서 흐름 안의 행과 칸으로 분리했다.
- A/B 비교: 모든 행동을 거의 같은 점 무늬로 나타냈다. 손과 물건, 기침 가리기, 창문과 공기 흐름, 개인 컵, 공용 음식과 덜기 도구를 각각 SVG로 표현했다.
- 태블릿의 P08: 그림을 키우면 차이 표시·결과 연결 조작이 아래로 밀렸다. 낮은 화면에서 그림과 여백을 줄였고, 1280×800·1366×768의 초기 화면에 조작이 모두 보이는 것을 측정했다.
- 터치 끌기: 새 일반 버튼 규칙이 드래그 대상의 `touch-action: none`을 덮는 문제를 교차 검토에서 발견해 수정하고 손가락 입력으로 재검증했다.
- 공통: 긴 한글의 줄바꿈, SVG 축소 방지, 패널 너비, 상단 도구와 브랜드 간격을 보완했다. 모바일 학습 화면에는 조사 지도로 돌아가는 버튼을 추가했고, 회전 안내가 제목을 가리지 않게 했다.

| 스테이지 | 개선한 학습 표현 |
| --- | --- |
| S1 관찰·단서 | 현장 사진과 조사 상태 분리, 스캔 표시, 단서 수집 진행 표시 |
| S2 관계·영향 | 단서 선택→상황 연결 안내, 생활 상황 도식, 나·주변·학교의 영향 범위와 이유 |
| S3 시간 추적·연구실 | 순서·흔적 상태 경로, 옷소매로 가리는 학생, 창문과 흐름, 물의 관리 정보, 음식과 접시 |
| S4 조건 비교 | 그대로 두는 조건과 바꾸는 행동 분리, 행동별 A/B 모형, 차이 표시와 근거 연결 |
| S5 계획·실천 | 장소 사진과 상황, 배치 상태와 에너지, 실천 순서와 손의 관찰 영역 |

## 검증 결과

- `npm run build`: 타입 검사·프로덕션 빌드·오프라인 캐시 목록 생성 통과. 기존 Phaser 분리 청크의 500KB 초과 안내는 남아 있다.
- `npm test`: 30/30 통과.
- 브라우저 반응형 검사: 26개 화면 상태 × 10개 해상도 × 기본/큰 글자 = 520개 조합. 가로 넘침, 화면 밖 조작, 작은 터치 영역, 버튼 밖 글자, 글자·아이콘 겹침, 잘린 글자, 깨진 그림 및 페이지 오류 검출 0건. 본문 처음과 끝을 스크롤해 검사했다.
- 해상도: 1920×1080, 1366×768, 1280×800, 1024×768, 1024×600, 915×412, 740×360, 800×270, 390×844, 360×740.
- 전체 플레이: 새 기록으로 메인→지도→P01~P10→엔딩·인증서 성공. 인증서 새로고침과 다시 실험 후 본편 기록 보존 확인.
- Chromium 터치 입력: P03 관계 연결, P04 영향 연결, P06 덜기 도구, P09 작전 배치, P10 최종 실천의 끌기 성공.
- 부분 갱신: P05 시간 이동에 따른 흔적 상태 갱신, 360px 큰 글자 상단 도구와 지도 복귀 버튼 확인.
- 실제 스크린샷: P01~P10, 연구실 4종, A/B 5행동 및 세로 폰의 주요 장면을 열어 확인했다.

작은 화면·큰 글자에서는 본문 스크롤을 허용하고 조작 영역과 글자 크기를 유지했다. 학교 실물 태블릿·삼성 인터넷·iOS에서의 손가락 조작과 회전은 미실측이다. SVG와 흔적은 실제 입자 수·감염 확률을 나타내지 않는 학습용 모형이며 기존 콘텐츠의 교사 검수 상태는 유지했다.
