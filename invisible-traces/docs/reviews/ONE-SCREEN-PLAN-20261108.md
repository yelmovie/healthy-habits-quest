# 한 화면 활동·자동재생 개선 계획

사용자 승인 범위: 각 스테이지의 장면과 조작을 스크롤 없이 배치하고, 중복 문구를 없애고, 다음 조작을 강조하며 판단 문제가 아닌 실험에 속도 선택 자동재생을 추가한다.

- 공통: 왼쪽 진행 패널과 별도 제목 행을 없애고 한 줄 헤더·큰 활동 영역·고정 하단 이동으로 통합한다.
- 스테이지: 긴 패널은 간결한 조작이나 같은 화면의 탭으로 전환한다. 정보와 조작을 숨기기 위해 overflow만 막는 방식은 쓰지 않는다.
- 자동재생: 관찰 스캔, 시간 경과, 정답 선택이 없는 실험, 확정된 계획의 실천을 시연한다. 물 고르기·단서·관계·영향·예측·결과 해석·작전 선택은 학생이 한다.
- 속도: 0.5배·1배·2배. 일시정지·속도 변경·화면 전환·설정 창·백그라운드 전환 시 타이머 수명을 관리한다.
- 보존: 기존 저장 스키마·진행 판정·본편/다시 실험 분리를 유지한다.
- 검증: 타입 검사·기존 테스트·자동재생 안전성 테스트·빌드, 대표 해상도별 실제 스크롤·가림·터치 영역 측정, 자동재생의 속도/중단/정답 미선택과 전체 플레이를 확인한다.

공통 렌더러/재생/브라우저는 한 작업자가, 스테이지 파일 세 묶음은 각 작업자가 병렬로 수정한다. 모든 작업 데이터와 임시·캐시·출력은 연결을 확인한 외장 SSD에 둔다.
