# 흐름·디자인 고도화 (2026-11-16~17)

요청: 버튼이 중복되거나 누르기만 반복되는 지루한 흐름을 찾아 직관적인 조작으로 바꾸고, 반복·CSS 그림을 새 그림으로 바꾸며, 배경을 가리는 불투명 카드와 핵심 개념을 건너뛰는 구간을 없앤다.

| P10 | 손 씻기는 글자 카드 세 장을 누르기만 함 | 지루함 |

## 2. 바꾼 것

- 자동재생은 관찰용(P05 시간 추적, P08 두 하루)만 남기고 '자동재생'(재생 중 '직접 해보기', 과학34 공통 표기) 버튼 하나로 줄였다. 속도 선택은 뺐다. 활동을 대신 끝내는 자동재생(P01·P06·P10)은 화면에서 없앴다(`demonstrationSteps`는 테스트용으로 유지).
- 안내 다시 듣기 버튼은 말풍선 아이콘으로 바꿔 소리 버튼과 구분했다.
- P01: 신호를 찾으면 그림 위에 무엇이 보였는지 한 줄이 뜬다.
- P02: 현장 그림을 원래 밝기로 보여 주고, 단서 카드는 아래쪽 반투명 유리 카드로 바꿨다.
- P05: 손 씻는 때를 두 번 이상 넣고 그중 가장 이른 때를 확인해야 완료된다(`timeline.tried`, `timingCompared`). 넣어 본 때마다 '흔적 n곳'이 남아 비교가 보인다. 사물 칸은 새 그림(책·공·문손잡이)과 기존 손 그림을 쓴다. 비교 전 저장 중 이른 손 씻기를 고른 기록은 완료로 보존한다.
- P06: 접촉 탭을 숨기고(P05 기록으로 자동 완료) 실험 4개 + 종합으로 줄였다. 결과를 본 뒤에만 '다음 실험' 큰 버튼 하나가 나온다. 종합 장면은 고른 행동에 따라 창문이 열리고 기침을 소매로 가린다. 물 실험은 점검된 정수기와 출처 모를 병 그림으로 바꿨다. 빈 접시를 가로 접시 모양으로 고쳤다.
- P08: 차이가 생기면 B 그림 위에 '달라졌어요!' 깃발이 뜨고, 결과는 큰 카드 세 장 중에서 고른다. 손 씻기 B 장면의 손 흔적을 지웠고 CSS 공을 새 공 그림으로 바꿨다.
- P09: 세 장소 카드에 해결할 문제가 보이는 새 장면(닫힌 교실의 기침, 공용 그릇, 손 씻기 전 간식)을 넣었다.
- P10: 확인 화면을 건너뛰고 바로 실천한다. 창문은 손가락으로 밀어 열고(버튼도 가능), 공용 음식은 빈 개인 접시로 덜며, 실천 결과를 약 1초 보여 준 뒤 넘어간다. 손 씻기는 카드를 문지르면 거품 막대가 차오른다(톡 누르기는 세 번, 키보드는 바로 완료).
- P04: 큰 빈 칸 속 아이콘을 생활 영역 그림(집에서 쉬는 아이, 빈자리가 생긴 모둠, 바뀌는 학급 일정)으로 바꿨다.

## 3. 스테이지별 조작을 서로 다르게

P03·P04·P09가 모두 '카드 고르고 → 대상 누르기'였다. 장마다 다른 손짓이 되도록 나눴다.

| 장 | 조작 |
| --- | --- |
| P01 | 돋보기를 그림 위로 움직여 숨은 보라 빛 찾기(빗나가면 찾지 못함, 키보드는 바로 찾기) |
| P02 | 현장 그림 위 단서 모으기·바꾸기 |
| P03 | 단서를 생활 상황 그림에 잇기 |
| P04 | 빠른 분류: 반짝이는 카드 한 장씩, 그림 하나만 누르기(클릭 6 → 3) |
| P05 | 비누 방패를 두 때 이상 넣어 흔적 수 비교 |
| P06 | 옷소매 끌어 가리기·창문 밀기·물 고르기·덜기 도구 끌기 |
| P07 | 그림 카드로 행동 하나 고르고 예측 |
| P08 | B 그림의 깃발로 달라진 곳 찍기 → 결과 카드 |
| P09 | 에너지 5 안에서 장소별 계획 배치 |
| P10 | 창문 밀어 열기 → 접시에 덜기 → 손 씻기 단계 그림 문지르기 |

## 4. 화면·팝업 디자인 (yelsam-design, 과학34 공통 방식 반영)

- 완성작(1·2·3·5·6·7번)처럼 활동 화면 뒤에 미션 장소 그림을 깔고(신호 광장·체육관·본관 교실·급식실·운동장), 카드는 반투명 유리로 바꿨다. 그림 톤에 맞춘 일러스트 게임 화면 예외를 적용했다.
- 학습 안내 팝업을 '미션 꼬리표 → 알아볼 것 → 다시 볼 단서·내 말로 설명 카드 2장 → 접힌 약속·성취기준'으로 줄였다. 팝업은 0.95→1 크기로 400ms에 열린다(동작 줄이기에서는 끔).
- 화면 안 안내가 하단 안내와 같은 말을 반복하던 곳(P05 방패 설명, P06 결과 줄, P09 상단 안내)은 결과가 생긴 뒤에만 보인다.
- 자동재생 표기는 과학34 공통 규칙(자동재생 ↔ 직접 해보기)을 따른다.
