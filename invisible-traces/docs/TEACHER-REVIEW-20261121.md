# 교사 검수표: 보이지 않는 흔적 (2026-11-21)

학습 문장을 코드와 데이터에서 그대로 옮겼다. 문장은 고치지 않았다. 화면에 굵게 보이는 글자의 태그(`<b>`, `<mark>`)만 빼고 글자는 원문 그대로다.
검수할 때 줄마다 「☐ 맞음 ☐ 고칠 것」 중 하나에 표시하고, 고칠 내용은 메모 칸에 적어 주세요. 「확인 필요」는 작성자가 보기에 다시 봐야 할 것 같은 줄이다.
