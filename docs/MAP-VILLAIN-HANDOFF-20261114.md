## 외형과 등장

**흔적 가면 / 자주색 후드, 큼직한 장갑과 손잡이에 남는 한 개의 형광 손자국.** 스테이지 완료 기록 후 지도에 돌아올 때 해당 장소 옆에 등장한다. 기존 주인공·동료·건물의 스타일을 유지하고, 악당과 소품의 접점이 글 없이도 읽히게 그린다. 아래 소품 동작은 지도 위 짧은 장난 컷이다. 활동 화면이나 기존 학습 데이터에는 손대지 않는다.

형광은 오염 이동을 보여주는 모형. 실제 병원체를 악당 캐릭터로 만들거나 접촉 피격을 감염·질병으로 표시하지 않는다.

## 스테이지마다 바뀌는 소품·자세·대사

장소명은 기획상의 연결 기준이다. 활성 버전의 스테이지 ID와 이름을 대조한 뒤 키를 정한다. 선택 구역은 실제 별도 완료 이벤트가 있을 때만 추가한다.

| 장소 | 악당 스프라이트 동작 | 첫 등장 또는 접근 대사 예시 |
|---|---|---|
| 이상 신호를 기록하라 | 손잡이에 형광 손자국 남기기 | “이 자국이 눈에 보일까?” |
| 단서의 관계를 밝혀라 | 접촉 단서 표지를 손등으로 가리기 | “단서 하나는 내가 가졌어!” |
| 흔적의 이동을 복원하라 | 도구와 손잡이에 차례로 손 대기 | “이번엔 어디에 묻었을까?” |
| 한 가지 행동을 바꿔라 | 비교용 손잡이 앞을 망토로 가리기 | “이쪽만 잠깐 가려 둘게!” |
| 학교 대응안을 설계하라 | 학교 지도 위 손자국 표식 찍기 | “내 표식은 꼭 남겨야지!” |

상황 대사 예시:

- 접근: “여기에도 내 손자국!” / “장갑 자국을 찾아낼 수 있을까?”
- 1·2타: “앗, 내 장갑이 미끄러워!” / “망토가 접혔잖아!”
- 퇴장: “손자국은 지우고 갈게!” / “형광 불빛 끄고 쏙!”

스테이지 고유 문장을 우선하고, 상황 대사는 연속 반복 없이 고른다. 주인공·보조 캐릭터의 주민 대화와 겹칠 때는 악당 말풍선을 생략한다.

## 세 번의 타격과 접촉 피격

| 사건 | 이 프로젝트의 표현 |
|---|---|
| 1타 · 짧은 명중 | 형광 점 두 개가 톡 |
| 2타 · 더 큰 반동 | 장갑 자국이 손잡이에서 잠깐 밝아짐 |
| 3타 · 마무리와 퇴장 | 망토가 접히고 손자국 조명이 차례로 꺼짐 |
| 주인공 접촉 | 주인공은 손을 황급히 거둬 한 발 물러남 |
| 보조 캐릭터 접촉 | 보조 캐릭터는 접촉 방향 반대로 움츠렸다 안정 |
| 악당의 접촉 공격 동작 | 장갑을 한 번 펴고 닿는 순간 캐릭터 발 옆에 손자국 한 개가 켜졌다 꺼짐. |
| 타격·퇴장 효과음의 차이 | 톡 → 뿅 → 소등음 |
| 접촉 효과음 모티프 | ‘톡’ + 짧은 소등음 |

세 타격은 같은 공격 입력이다. 가까이 있는 상태에서 한 입력이 한 타로 계산된다. 접촉 피격은 닿은 쪽만 재생하고 공격 카운트와 학습 진행에는 영향을 주지 않는 것을 권장한다. 소리를 꺼도 표정·자세·게이지로 읽혀야 한다.

## 방향과 시선

[공통 방향 규칙](../../_shared/MAP-VILLAINS-HANDOFF-20261114.md#방향시선공격-자세)을 적용한다. 손자국은 손잡이에 붙어 있고 악당의 시선과 장갑만 돌아선다. 실제로 닿은 쪽에서만 접촉 효과를 재생한다.

## 제작하고 적용할 순서

1. 기존 진입점 확인: [invisible-traces/src/data/game.ts](../invisible-traces/src/data/game.ts) · [invisible-traces/src/data/content.json](../invisible-traces/src/data/content.json) · [docs/STAGE_CONTENT.json](../docs/STAGE_CONTENT.json). 활성 지도와 완료 상태, 실제 주인공/보조 지도 원본·이름, 기존 악당/스프라이트·대사·저장부터 확인한다.
2. 기본 악당 한 장, 위 표의 장소별 소품 동작 스트립, 공통 이동/접촉 전조/피격/퇴장 프레임을 제작한다. 주인공·보조 피격은 각각 4~6프레임. 소품이나 배경을 몸통 시트에 같이 구워 넣기 전에 지도 크기에서 알아볼 수 있는지 확인한다.
3. 별도 승인된 구현 단계에서 완료된 장소 좌표에 악당을 붙이고, 기존 HUD 근처에서 공격·타격·피격·퇴장만 연결한다. 기존 이동/화면 전환/복구 상태와 학습 완료/다음 장소 해금은 보존한다.
4. 완료 전/후, 정확한 3타, 두 아군의 개별 접촉, 퇴장 및 재진입, 빠른 연타, 무음·모션 감소·태블릿을 확인한다. 가장 작은 정상 지도 표시 크기에서 소품과 방해 동작이 구분되는지 본다.

완료된 것: 정적 이미지 합성과 계획. 남은 것: 기존 시트/캐릭터 일치 확인, 프레임 제작, 대사 최종화, 구현 및 테스트. 06 물의 상태 변화는 참고 전용.
