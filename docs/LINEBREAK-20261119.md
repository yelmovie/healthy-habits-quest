## 고친 곳

- `invisible-traces/src/korean-linebreak.css`: 공통 규칙 복사(keep-all·pretty·제목/버튼/팝업 balance). `invisible-traces/index.html`에서 다른 스타일보다 먼저 링크. 빌드에서 메인 CSS(`index-*.css`) 맨 앞에 합쳐지고 프리캐시 목록에 들어간다.
- 같은 파일 「프로젝트 보정」:
  - `.topbar-focus { text-wrap: balance; }` — 넓은 화면 위 띠의 질문·개념 문구(두 줄이라 pretty로는 안 고쳐짐).
  - `.modal:has(.science-recall) { width: min(800px, 100%); }` — 연구 기록 창만 640→800px. 개념 카드 칸 170→약 223px라 제목이 한 줄에 들어간다. 1024·1280·1920·915 가로에서 창이 화면 안, 넘침 0.
