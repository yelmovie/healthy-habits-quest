## 조사 지도 고도화 (2026-11-07)

운영 시트의 완료작 5개(우당탕 힘 실험실, 동물기록 복구작전, 초록정원, 생명 시계, 밀고 당기는 도시)의 지도 방식을 참고해 C01을 다시 만들었다.

- 화면: 작은 지도 칸과 오른쪽 목록을 없애고 지도를 화면 전체에 깔았다. 도구는 그 위에 떠 있다. 왼쪽 아래 방향 버튼, 오른쪽 아래 다음 미션 카드와 번호 빠른 이동, 장소 이름표(완료·지금 조사·잠김).
- 그림: `image/` 19번 학교 그림과 30번 인물을 픽셀아트로 변환했다(`public/assets/school-map.webp`, `map-team.webp`). 다시 만들 때는 `scripts/build-map-assets.cjs`를 쓴다. 새 생성 이미지는 쓰지 않았다.
- 이동: 카메라가 조사팀을 따라간다. 방향키·WASD·방향 버튼(톡 누르면 한 걸음, 꾹 누르면 계속)으로 길을 걷고, 길 근처를 누르면 그곳까지 걷는다. 지도를 끌면 둘러보고, 다시 걸으면 따라 보기로 돌아온다. 동료가 뒤따라온다.
- 입장: 이름표·건물·다음 미션 버튼은 걸어가서 바로 입장한다. 방향키로 다음 미션 장소에 닿아도 입장한다. 이미 끝낸 장소는 지나가기만 하고, 이름표나 Enter로 다시 실험한다.
- 지도 복귀 시 위치를 유지한다(새로고침하면 마지막 완료 장소에서 시작).
- 다섯 장소 이름(신호 광장·체육관·본관 교실·급식실·운동장)은 지도에 맞춰 새로 정한 값이라 교사 검수 대상이다.

검증: `npm run check`, `npm test` 25/25(지도 길 찾기 12개 추가), `npm run build` 통과. 1920×1080·1280×800·1024×768·915×412·390×844에서 버튼 크기·화면 밖·가림·글자 크기·패널 겹침을 측정했다. 터치 끌기와 꾹 누르기는 실기기에서 확인하지 못했다.

## 당시 남은 일 — 현재 상태는 문서 맨 위 참고

1. 실기기 확인: 학교 태블릿(크롬·삼성 인터넷·QR 접속)에서 터치 끌기, 지도 끌기·방향 버튼 꾹 누르기, 소리, 회전, 주소창 표시 상태를 확인한다. 헤드리스 브라우저로는 확인하지 못했다.
2. 전자칠판에서 뒷자리 가독성을 확인한다.
3. 인증서 인쇄(`window.print`)를 실제 프린터나 PDF 저장으로 확인한다. 화면 표시와 인쇄용 CSS는 넣었지만 출력물은 보지 못했다.
4. 교사 콘텐츠 검수: `content.json`의 `status`가 아직 draft다(`contentVersion 1.0.0-draft`). 문구·과학 개념 표현 검수 뒤 버전을 올린다. 버전을 올리면 기존 저장은 보호되고 새 연구로 시작한다(sanitize 정책).
5. 배포: 대상 호스팅이 정해지지 않았다. Vercel이라면 `vercel.json`(빌드 명령·출력 폴더)을 추가하고, 배포 URL로 시작→1스테이지→새로고침을 확인한다.
6. 큰 글자 설정을 켜면 1280×800에서도 P03·P05·P06·P07·인증서 본문이 스크롤된다. 조작은 모두 닿지만, 더 줄일지는 교사 의견을 듣고 정한다.

## 보존한 사용자 요구

선택 맵만 비스듬히 내려다보는 2.5D 픽셀아트 RPG이고, 나머지 메인·학습·엔딩은 2D다. 학습 10장과 공통 메인·선택 맵을 구분한다. 중복 확인·재선택·의무 슬라이더 왕복을 줄이고, 관찰·근거 연결·개입 시점·한 변인 비교·전략 수정·직접 실천을 유지한다.

image/와 files/의 원본·샘플 ZIP은 로컬에 보존하며 .gitignore로 제외했다. Git에는 게임용 압축 이미지, 설계 문서, 소스·잠금 파일을 저장한다.
