# 작업 재개 메모

기록일: 2026-10-28
중단 사유: 사용자가 현재 상태를 Git에 저장하고 종료하도록 요청함.

## 저장소와 프로젝트

- 프로젝트명: 보이지 않는 흔적
- 단원: 초등 3학년 2학기 과학, 감염병과 건강한 생활
- 사용자 제공 운영 시트의 이예리 선생님 탭 17행, NO.12에서 저장소를 확인함.
- 저장소: https://github.com/yelmovie/healthy-habits-quest
- 앱 경로: invisible-traces/

## 완료한 작업

- PRD, TRD, 5스테이지·학습 10장의 시나리오와 설계 데이터.
- TypeScript, Vite, Phaser 프로젝트 구성과 package-lock.json.
- 2.5D 픽셀 선택 맵 코드, 메인 및 10개 학습 화면 템플릿.
- 단서·관계·되감기·A/B 비교·작전 예산·마지막 실천의 상태와 입력 연결.
- 기본 저장·복구, 연구 노트·교사용 시연·설정·인증서 화면 코드.
- 원본 이미지에서 게임용 WebP 배경 10개를 압축하고 public/assets에 저장함.

위 항목은 작성된 코드의 범위이며 플레이 검증을 통과한 완성 기능을 뜻하지 않는다.

## 현재 검증 상태

- npm install 완료.
- npm run check 통과.
- npm run build 실패: src/main.ts에서 가져오는 ./ui/style.css가 아직 없음.
- 스타일 전체를 저장하려던 명령이 Windows 명령 길이 제한으로 실행되지 않아 CSS 파일이 저장되지 않았음.
- 앱 브라우저 실행, 전체 스테이지 플레이, 태블릿 실기기 검증은 아직 수행하지 않음.
- npm test 명령은 설정되어 있으나 tests/*.test.ts 파일은 아직 작성되지 않음.
- docs/DESIGN_VALIDATION.md는 설계 데이터 검증 결과이며 게임 실행 검증 결과가 아님.

## 재개 순서

1. src/ui/style.css를 여러 작은 쓰기 단위로 작성하고 빌드를 통과시킬 것. 전체 파일을 한 Windows 명령 인자로 쓰면 길이 제한에 걸릴 수 있음.
2. src/main.ts의 비교 타임라인 input 처리에서 전체 DOM 교체로 터치 드래그가 끊길 수 있는 부분을 수정할 것.
3. 완료된 기록의 읽기 전용 정책이 select/change 경로에서도 지켜지도록 확인할 것.
4. P06 접촉 기록은 진입 시 자동 상속되므로 추가적인 필수 기록 버튼이 필요하지 않은지 정리할 것.
5. 비교 재생의 play/pause 표시와 타이머 정리, 초기·중간 새로고침을 점검할 것.
6. 되감기 모형, 예산 환급, 저장 sanitize, 중복 최종 적용의 의미 있는 회귀 검사를 작성할 것.
7. 빌드 후 메인→선택 맵→P01~P10 전체 성공·실패 흐름을 실제 브라우저에서 확인할 것.

## 보존한 사용자 요구

선택 맵만 비스듬히 내려다보는 2.5D 픽셀아트 RPG다. 나머지 메인·학습·엔딩은 2D다. 학습 10장과 공통 메인·선택 맵을 구분한다. 중복 확인·재선택·의무 슬라이더 왕복을 줄이고, 관찰·근거 연결·개입 시점·한 변인 비교·전략 수정·직접 실천을 유지한다.

image/와 files/의 원본·샘플 ZIP은 로컬에 보존하며 .gitignore로 제외했다. Git에는 게임용 압축 이미지, 설계 문서와 소스·잠금 파일을 저장한다. 게임 생성이라는 별도 설치 스킬은 없어서 edu-webapp과 game-feel-polish 기준을 적용했다.
