## 기본 작전 계산

- 가능한 행동·구역 조합의 부분집합 64개를 열거했다.
- 예산 안의 배치는 51개, 세 핵심 요구를 충족하는 배치는 1개다.
- 유효 예시: cafeteria / 음식 덜어 먹기, classroom / 환기, gym / 손 씻기 — 총비용 5.
- 질문권 0~3회를 사용하는 서로 다른 선택 집합은 42개다. 질문을 필수 진입 조건으로 사용하지 않는 설계이므로 질문 선택만으로 계획 실행이 잠기지 않는다. 실제 힌트 표시·이해 가능성은 앱에서 확인해야 한다.

## 되감기 예시 계산

고정된 사건 목록에서 접촉 기록을 순서대로 계산하는 검증용 모형을 사용했다. 초기 상태와 같은 사건으로 다시 계산하며 1.5 tick 개입과 2.5 tick 개입의 후속 상태가 다름을 확인했다. 이 계산은 구현된 게임 엔진의 회귀 테스트가 아니다.

## 남은 검증

- 실제 게임 빌드·타입 검사·브라우저 전체 플레이. 현재 package.json과 게임 코드는 없다.
- 터치·키보드·모션 감소·음소거·저장 손상·새로고침·장면 이탈.
- 픽셀 맵·캐릭터 제작, 배경 최적화와 실제 요청 수·용량 측정.
- 물·음식·기침 등의 구체 문구와 과학적 모형의 교육 콘텐츠 검수.
- 실제 3학년의 이해도·반복 피로와 30대 교실망 동시 접속.

## 설계 선택

학습 10장 외 공통 화면 2개, 질문권 3회와 예산 5, 핵심 관계 가지 2개 등은 현재 초안의 작업 기준이다. 검증 통과는 이 선택의 교육적 적절성이나 사용자 최종 승인을 뜻하지 않는다.
