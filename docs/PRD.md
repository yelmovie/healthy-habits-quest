# 보이지 않는 흔적 PRD

문서 버전: 1.0 설계 초안 · 2026-10-28
대상: 초등학교 3학년 과학 「감염병과 건강한 생활」
상태: 구현을 위한 제안 기준. 앱 구현·배포·실기기 검증 전.

## 1. 목적과 범위

학생이 학교의 이상 신호를 관찰하고, 생활 행동과 환경의 관계를 추적·실험한 뒤, 자신이 세운 예방 행동 계획을 직접 적용하는 과학 탐구 게임을 만든다. 태블릿에서 시간을 되감고, 조건을 고정하고, 결과를 같은 시각에 비교하는 경험이 학습의 중심이다.

이번 산출물은 PRD·TRD와 장별 설계 데이터다. 기존 실행 코드와 패키지는 없다. 기존 샘플은 시각·상호작용의 참고이며, 화면 전체를 이미지 버튼처럼 사용하지 않는다.

| 구분 | 기준 |
|---|---|
| 제목 | 보이지 않는 흔적 |
| 대상 기기 | 태블릿 가로형, 데스크톱, 전자칠판 |
| 학습 구성 | 5스테이지, 스테이지당 2장, 학습 P01~P10 |
| 공통 화면 | C00 메인, C01 스테이지 선택 맵 |
| 표현 | C01만 고정 시점 2.5D 픽셀아트 RPG. C00·P01~P10·엔딩은 2D |
| 저장 | 기기 내 자동 저장과 이어하기. 개인정보 입력 불필요 |
| 기본 배포 형태 | 정적 웹앱. 실제 호스팅·배포 작업은 구현 후 범위에서 다룸 |

**화면 수 해석:** 학습 10장과 공통 진입 2개를 구분하는 작업안이다. 이전 대화의 ‘총 10화면에 메인 포함’ 안과 ‘각 미션 2장’ 요구가 충돌하므로 후자의 학습 분량을 보존했다. 사용자 수정 시 이 표와 JSON을 함께 바꾼다. 엔딩·보고서·인증서는 P10의 상태 또는 오버레이이며 추가 학습 장으로 세지 않는다.

## 2. 설계 근거와 교육 범위

[공유 대화의 최종 심화안](https://chatgpt.com/share/6acef53e-da6c-83ee-accd-a4f3ed4a6ce3), 현재 폴더의 샘플 10장, 최신 대화의 픽셀 맵 한정 지시와 반복 조작 감축 요청을 기준으로 삼는다. 과거의 Full 3D 메인·교실·전략맵·엔딩 제안은 적용하지 않는다.

| 성취기준 | 학습의 초점 | 연결 화면 |
|---|---|---|
| [4과08-01] | 생활 속 감염병 사례와 위험성 이해·토의 | P01~P04 |
| [4과08-02] | 여러 감염 과정, 생활 습관과 유행의 관계 설명 | P05~P09 |
| [4과08-03] | 예방 수칙 공유와 생활 속 실천 | P09~P10, 연구 기록 공유 |

기준은 3~4학년군이며 이 프로젝트의 대상은 3학년이다. 기준 문구는 [경기도교육청 공식 편성 안내](https://www.goe.go.kr/resource/old/BBSMSTR_000000030136/BBS_202312210923589990.pdf) 본문 95쪽과 대조한 기존 조사에 따른다. 토의·공유는 앱 기록을 화면에서 발표하고 친구와 비교하는 교실 활동으로 연결한다. 멀티플레이 서버는 요구하지 않는다.

### 과학 표현

- 모형의 빛·연결·신호는 실제 병원체 수, 감염자 수, 개인 감염 확률이 아니다. 처음 등장할 때 짧게 안내하고 교사용 설명에서 다시 확인할 수 있다.
- 접촉·비말·공기·물·타액은 생활 장면을 이해하기 위한 다섯 묶음이다. 서로 완전히 구분되는 의학 분류나 병명별 단일 정답으로 제시하지 않는다.
- 관찰 단서만으로 특정 학생의 감염이나 정확한 원인을 확정하지 않는다. 사람의 이름 대신 행동·물체·환경과 시간 순서를 조사한다.
- ‘손을 씻으면 감염되지 않음’, ‘면역력 100%’, ‘창문을 열면 즉시 완전 안전’ 같은 표현은 쓰지 않는다.
- 호흡기 관련 예방 표현은 위생과 깨끗한 공기 등 위험을 낮추는 생활 행동이라는 수준으로 다룬다. [CDC의 예방 안내](https://www.cdc.gov/respiratory-viruses/prevention/index.html)
- 물의 안전은 색이나 투명도로 판정하지 않는다. 제공된 공급·관리 정보에 근거해 선택한다.
- 게임 에너지는 계획상의 제약이다. 현실에서 필요한 예방 행동을 일부러 생략하라는 의미가 아니다.
- 구체적인 병명 사례와 생활 장면의 문구는 구현 콘텐츠 검수 때 공식 교육·보건 자료로 확인하고 출처를 데이터에 덧붙인다. 진단·치료 기능은 범위에 없다.

## 3. 핵심 경험과 공통 진행

의뢰 수령 → 관찰 → 관계 해석 → 시간 추적 → 한 변인 비교 → 대응 계획 → 직접 적용 → 학교 변화 → 연구 결과 공유.

조작 직후 해당 대상이 반응하고 유효한 변경은 자동 저장한다. 실패하면 같은 화면에서 설명되지 않은 부분만 고친다. 생각할 필요가 없는 팝업 확인, 저장, 다음의 연쇄는 없앤다.

### 전환 규칙

1. 작은 실험의 결과는 같은 화면에 펼쳐진다. 결과 애니메이션이 끝나야 진행할 수 있는 잠금은 두지 않는다.
2. 일반 장 완료는 성공 표시와 함께 `계속` 하나를 제공한다. 결과를 읽기도 전에 강제로 화면을 넘기지 않는다. 성공 표시와 별도 확인 팝업을 겹치지 않는다.
3. P01의 마지막 조사 장소 선택, P07의 예측 선택은 이미 다음 행동의 의도가 있으므로 다음 상태로 자연스럽게 이어진다.
4. 스테이지 완료 뒤에는 다음 미션으로 바로 이동할 수 있다. 지도 복귀는 선택이다.
5. 스테이지를 나갔다 돌아오면 완료한 단서·실험·질문을 보존한다. 긴 설명은 다시 자동 재생하지 않는다.

## 4. 공통 화면과 캐릭터

### C00 메인

밝은 2D 학교 일러스트와 제목, `시작` 또는 저장 상태에 따른 `이어하기`를 중심으로 둔다. 홈·소리·설정과 교사용 안내에 접근할 수 있다. 새 연구 시작으로 기존 기록을 지울 때는 저장된 기록을 지운다는 설명과 확인을 제공한다.

### C01 스테이지 선택 맵

자연 경관이 있는 학교 주변 길에 다섯 조사 장소를 배치한다. 비스듬히 내려다보는 고정 시점의 픽셀아트와 작은 이동 캐릭터를 사용한다. 목적지 한 번 선택 → 짧은 경로 이동 → 입장으로 이어진다. 문 클릭과 입장 확인은 요구하지 않는다. 빠른 이동과 큰 DOM 목록에서도 동일한 장소를 선택할 수 있다.

맵은 미션 선택과 누적 변화 표시용이다. P01에서 같은 RPG 맵을 다시 탐색하지 않는다. 완료에 따라 발견 위치·관계선·분석 정보·행동 적용 표시가 누적되며, 잠금은 색과 자물쇠·문구로 함께 표시한다.

### 역할

- 보건 선생님: 조사 의뢰, 짧은 과학 설명, 연구 결과 해석.
- 관찰 담당: 스캐너 시연과 현장 힌트.
- 기록 담당: 사건 타임라인과 연구 노트.
- 실험 담당: 조작 예시와 재실험 안내.

캐릭터는 설명이나 조작 역할이 있는 순간에 등장한다. 화면 양쪽을 상시 점유하거나 정답을 먼저 말하지 않는다.

## 5. 스테이지별 학습과 판정

### S1 이상 신호를 기록하라

**질문:** 어디를 살펴보고 어떤 정보를 남겨야 할까?

**P01 이상 신호 관찰:** 2D 관제판의 교실·급식 공간·체육 활동 공간에서 스캐너로 세 신호를 발견한다. 넓은 판정 영역을 한 번 지나면 발견 상태가 유지된다. 스캐너를 움직이기 어려울 때는 큰 `살펴보기` 대상 선택으로 같은 정보를 얻는다. 세 신호를 발견한 후 조사 장소를 고르면 P02가 그 현장에서 열린다.

**P02 사건 현장 조사:** 관련 단서 5개와 방해 단서 3개 중 최대 5개를 기록한다. 단서 선택은 즉시 증거함에 반영된다. 5칸이 찼을 때 관계있는 핵심 단서가 모두 있는지 판단하고, 부족하면 교체할 대상을 학생이 고른다. 자동으로 임의의 단서를 버리지 않는다. 슬롯 5개를 채웠다는 사실만으로 완료하지 않는다.

예시 핵심 단서는 닫힌 창문, 공용 공, 체육 후 손 씻기 생략, 개인 숟가락으로 공용 음식 먹기, 가리지 않은 기침 장면이다. 운동화 끈처럼 다른 안전에는 중요하지만 현재 사건을 설명하지 않는 정보도 섞는다. 최종 판정 데이터는 `STAGE_CONTENT.json`의 CL01~CL08이다.

**완료:** 핵심 단서 5개가 선택되면 E1 현장 관찰 기록 생성. 선택한 이유는 짧은 구두 발표나 선택적 메모로 공유하며 긴 글 입력은 필수가 아니다. P02에서 잘못 고른 부분만 교체할 수 있다.

### S2 단서의 관계를 밝혀라

**질문:** 단서들은 어떻게 관련되고 학교생활에 어떤 영향을 줄까?

**P03 증거 분석실:** E1 단서를 그대로 불러온다. 사람과 생활 장면을 나타내는 기본 노드는 제공한다. 학생은 단서를 배치하며 관계를 연결한다. 접촉 관련 가지, 함께 있는 환경과 기침 관련 가지, 식기·음식 관련 가지 중 서로 다른 2개를 설명하면 통과한다. 배치 좌표나 카드 번호 순서가 아닌 관계의 의미로 판정한다. ‘관찰만으로 실제 감염 원인 확정’이라는 인과선은 생성하지 않는다.

**P04 생활에 미치는 영향:** `몸이 아파 등교가 어려운 친구가 있는 상황`을 별도 생활 사례로 제시한다. 나·주변 사람·학교생활 영역에 영향과 근거를 연결한다. 같은 카드를 분류한 뒤 다시 끌어 담지 않고 배치 결과에 설명선을 이어 완성한다.

**완료:** P03의 유효한 관계 가지 2개와 P04의 세 영역별 근거 연결을 확보하면 E2 사건 연결 도식 생성. 누락된 가지·영역만 다시 살펴본다. 화면 기록을 교실 토의에 그대로 쓴다.

### S3 흔적의 이동을 복원하라

**질문:** 어떤 순서로 연결됐고 어느 시점에 행동을 바꾸면 이후가 달라질까?

**P05 시간을 되감아 추적:** 공·책·문손잡이가 있는 2D 교실 사건을 재생한다. 시간 손잡이를 움직이면 인물·물체·흔적 상태가 같은 시점으로 돌아간다. 최초 신호 물체를 짚고 전달 순서를 살핀 뒤 손 씻기 행동을 시간 경계에 넣는다. 늦게 손을 씻어도 이미 다른 물체로 옮겨진 기록은 되돌려 지우지 않는다.

기본 예시는 책 → 학생 A의 손 → 공 → 학생 B의 손 → 문손잡이 → 학생 C의 손이다. 모형에서 책의 초기 신호가 시작점이다. 책을 만진 뒤 공을 만지기 전에 손 씻기를 넣으면 이후 연결이 달라진다. 타임라인을 특정 횟수 왕복하는 조작은 통과 조건이 아니다.

**P06 다섯 경로 연구실:** 접촉 기록은 P05에서 가져와 차이를 해석한다. 나머지는 옷소매로 가리기, 창문 밀기, 물의 관리 기록 확인, 덜기 도구·개인 접시 배치로 탐구한다. 장치당 같은 조건의 전후 상태를 관찰하면 기록된다. 다섯 번의 시작·확인·완료 팝업을 만들지 않는다. 한 장 안에서 현재 장치를 크게 열고 다른 장치는 탭으로 바꾼다.

종합 장면에서는 닫힌 교실의 기침 상황을 보고, 기침 예절과 환기가 각각 어떤 상황을 바꾸는지 근거를 연결한다. 이것은 병명 맞히기가 아니다.

**완료:** P05의 시작·순서·개입 기록, 다섯 생활 상황의 관찰 기록, 종합 장면의 해석으로 E3 감염 과정 분석 기록 생성. P06에 P05 기록이 없으면 접촉 완료를 위조하지 않고 P05로 안내한다.

### S4 한 가지 행동을 바꿔라

**질문:** 나머지가 같을 때 행동 하나를 바꾸면 무엇이 달라질까?

**P07 행동 조건 실험실:** 동일한 교실 점심 장면의 기본 결과를 최초 한 번 관찰한다. 손 씻기·기침 예절·환기·개인 물품·음식 덜어 먹기 중 하나를 선택한다. 사람·장소·시간·사건 순서와 관찰 시각은 고정한다. 새 행동 선택은 앞선 선택을 교체한다. `줄어들 것 같다 / 비슷할 것 같다 / 아직 모르겠다` 예측을 고르면 변경 실험이 시작된다. 예측이 빗나가도 실패 처리하지 않는다.

**P08 두 개의 하루:** 같은 시각의 A/B 결과를 나란히 보여준다. 공통 타임라인으로 차이가 드러난 시점을 찾고 변화 지점 1개와 원인·결과 1개를 연결한다. 관찰할 차이가 한 가지인 실험에 두 개를 억지로 찾게 하지 않는다. 비교 슬라이더는 선택 도구이며 왕복 횟수는 검사하지 않는다.

**완료:** 다른 조건이 같음을 확인할 수 있는 A/B 기록, 한 행동, 예측, 관찰 지점과 설명으로 E4 생성. 다른 행동 재실험 때 기본 결과는 재사용한다. P05는 시간·개입 시점 추적, P07~P08은 한 변인 비교라는 차이를 유지한다.

### S5 학교 대응안을 설계하라

**질문:** 확인한 정보와 배운 내용을 이용해 어떤 행동을 어디에 적용할까?

**P09 연결 차단 작전:** 2D 학교 전략 보드에 교실·급식실·체육 활동 공간을 표시한다. 질문권은 3회, 대응 에너지는 5다. 답변은 모두 사실이며, 같은 답을 다시 읽을 때 질문권은 들지 않는다. 질문은 선택이고 기존 E1~E4를 다시 펼쳐 볼 수 있다.

| 행동 | 비용 | 현재 기본 사건의 적용 위치 |
|---|---:|---|
| 환기 | 2 | 교실 |
| 음식 덜어 먹기 | 1 | 급식실 |
| 손 씻기 | 2 | 체육 활동 후 |
| 기침 예절 | 1 | 교실의 기침 관련 가지 |
| 개인 물품 사용 | 1 | 개인 도구 관련 보조 가지 |

기본 사건의 핵심 세 상황은 교실 환기, 공용 음식에 쓰는 도구, 체육 후 손과 간식이다. `환기 2 + 덜어 먹기 1 + 손 씻기 2 = 5`가 해결 가능한 계획 예시다. 기침 예절 등의 행동도 해당 가지에 효과가 있으며 틀린 예방 수칙으로 표시하지 않는다. 현재 계획에서 다른 핵심 연결이 남았음을 보여준다.

에너지는 누적 소모 재화가 아니라 **현재 배치의 비용 합**이다. 카드를 빼거나 바꾸면 전액 돌아온다. 잘못된 구역에 놓으면 원위치로 돌아가며 비용을 차감하지 않는다. 같은 행동을 같은 구역에 중복 배치하지 않는다. 확인한 답변과 연구 기록은 재시도에도 유지한다.

`작전 실행`은 계획 전체를 시험하는 의미 있는 결정으로 유지한다. 결과는 해결된 곳과 연결이 남은 곳을 함께 보여준다. 질문을 모두 써도 남은 원인에 대한 문맥 힌트를 제공하여 막히지 않게 한다. 학생이 카드 선택 후 장소를 눌러도 드래그와 같은 결과를 얻는다.

**P10 나의 계획을 직접 실천:** P09가 유효해지면 E5 설계도를 생성하고 계획을 고정해 가져온다. 연구 기록 다섯 개는 자동 정리한다. P09에서 선택한 행동을 다시 고르지 않는다. 창문 열기, 개인 접시로 덜기, 손의 여러 영역을 살피는 축약 조작 등으로 각 계획을 실제 장면에 적용한다. 큰 터치 대안도 같은 적용 상태를 만든다.

손 씻기 장면은 실제 충분한 손 씻기 시간을 판정하는 장치가 아니다. 의무 문지르기 시간·클릭 횟수·카메라 인식으로 완료를 막지 않는다. 행동 적용 뒤 별도 확인 버튼 없이 다음 대상이 강조된다.

**완료:** P09의 모든 계획 항목이 적용된 시점에 S5를 완료한다. P09에서 E5가 생성됐다는 이유만으로 엔딩·인증서를 해금하지 않는다. 학교 회복 → 짧은 엔딩 → 기록·인증서로 이어지고 엔딩은 건너뛰거나 다시 볼 수 있다. 학교의 회복은 이야기상의 완료이며 현실의 감염 위험 0%를 뜻하지 않는다.

## 6. 기록과 보상

| 기록 | 생성 지점 | 최소 보존 내용 |
|---|---|---|
| E1 현장 관찰 기록 | P02 | 장소, 선택 단서 |
| E2 사건 연결 도식 | P04 | 관계 가지, 영역별 영향과 근거 |
| E3 감염 과정 분석 기록 | P06 | 연결 순서, 개입 시점, 모듈 관찰과 해석 |
| E4 A/B 비교 실험 기록 | P08 | 같은 조건, 바꾼 행동, 예측, 변화 지점과 설명 |
| E5 학교 건강 대응 설계도 | P09 | 질문, 근거, 계획, 비용, 수정 기록 |

코인과 순위 대신 실제 기록과 학교 변화가 보상이다. 최종 탐구 스타일은 플레이 기록에 기반한 서술형 한 줄로 제공하며 우열이나 고정 능력 점수로 평가하지 않는다. 인증서는 실명 없이도 출력할 수 있다. `연구 기록 공유`는 화면 발표·기기 인쇄를 의미하고 서버 전송을 요구하지 않는다.

완료된 기록은 읽기 전용으로 보존한다. `다시 실험`은 별도 재실험 세션에서 실행하여 기존 본편 결과와 이후 기록을 바꾸지 않는다. 본편을 새로 시작할 때만 초기화 범위를 설명한다.

## 7. 시각·반응형·접근성

밝은 청록·하늘색·흰색을 중심으로, 보라색 흔적과 주황색 주의를 절제해 사용한다. 버튼·패널·카드·설명은 DOM/CSS, 선과 판정은 SVG/게임 로직이다. 캐릭터·배경 이미지는 독립된 그림이다.

- 학습 질문은 한 화면에서 한 가지를 중심으로 1~2문장만 보인다.
- 가로 태블릿과 16:9 전자칠판에서 제목·중심 대상·하단 조작을 분리한다. 본문은 18~22px 수준, 큰 화면 모드에서는 더 크게 제공한다.
- 실제 CSS 터치 영역 최소 44px, 주요 버튼 48~56px 이상. 축소 화면에서도 이 최소값을 유지한다.
- 스캐너·카드·창문 등 직접 조작에는 동등한 큰 대상 선택 방식을 제공한다. 키보드 포커스로 선택·연결·실행 가능하게 한다.
- 색+아이콘+문구로 상태를 전달한다. 음소거로 학습 정보가 사라지지 않는다. 모션 감소를 지원한다.
- 세로 화면은 학습을 강제 중단하지 않고 패널을 재배치하고 가로 전환 안내를 선택적으로 제공한다.
- 팝업은 하나의 공통 레이어를 사용하며 뒤의 UI와 게임 입력을 함께 막고 닫을 때 복구한다.

## 8. 에셋과 초기 접속

원본은 현재 `image/`와 `files/`에 보존한다. 합본·전체 UI 샘플은 런타임 배포 파일에 넣지 않는다. 사용 후보는 `chatgpt_generated_19.png~28.png`, 제목 후보 29, 캐릭터 참고 30이다. 캐릭터 시트의 투명도·분할 상태와 오브젝트의 독립 판정 가능 여부는 제작 단계에 확인한다. C01 픽셀 맵·이동 캐릭터·잠금/해금 장소는 별도 제작이 필요하다.

처음에는 앱 껍데기와 메인 배경 등 최소 파일만 읽고, 선택 맵과 각 스테이지 자산은 진입 시 읽는다. 학교망 30대 동시 첫 접속을 목표로 하며, 구체적인 요청·용량 예산은 TRD에 명시한다. 실제 네트워크·기기 검증 전에는 통과했다고 보고하지 않는다.
